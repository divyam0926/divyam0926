## Featured Project

### 📚 Book Exchange Portal

A Java-based web application designed to provide students with a platform to **buy, sell, and exchange books**.

**Tech Stack:**

`Java` `JSP` `Servlets` `MySQL` `JDBC` `Maven` `Apache Tomcat`

**Key Features:**

- User registration and login
- Session-based authentication
- Add and manage book listings
- Search books by title, author, category, or ISBN
- Book pricing and condition information
- Exchange request management
- MySQL database integration
- Student-focused book exchange functionality

🔗 **Repository:**  
[Book Exchange Portal](https://github.com/divyam0926/Book-Exchange-Portal)
